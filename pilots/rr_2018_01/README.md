# Piloto RR 2018-01

Esta pasta concentra os artefatos do piloto de Roraima para evitar mistura com resultados gerais do projeto ou com pilotos futuros.

- `code/`: scripts de montagem dos paineis, SCM, medias moveis, especificacoes alternativas, ridge e augmented SCM.
- `data/`: paineis analiticos especificos do piloto.
- `output/`: tabelas, diagnosticos e figuras gerados pelo piloto.
- `notes/`: especificacao, validacoes e relatorios metodologicos do piloto.

Relatorio principal: `notes/results_report.md`.
